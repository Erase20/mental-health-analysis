# 心理健康用户画像分析系统 - 技术文档

## 一、项目概述

本系统是一个基于机器学习的心理健康数据分析与用户画像平台，通过收集心理健康调查数据，运用聚类和分类算法进行深度分析，生成用户画像与风险评估报告。

### 1.1 技术栈

| 层级 | 技术选型 | 版本 |
|------|---------|------|
| **前端框架** | Vue 3 + Vite 5 | 3.4 / 5.4 |
| **UI 组件库** | Element Plus | 2.5 |
| **图表引擎** | ECharts | 5.4 |
| **状态管理** | Pinia | 2.1 |
| **路由** | Vue Router | 4.2 |

| **后端框架** | Flask | 2.3.3 |
| **ORM** | SQLAlchemy | 2.0.23 |

| **认证** | Flask-JWT-Extended | 4.5.3 |
| **密码加密** | bcrypt (Flask-Bcrypt) | 1.0.1 |
| **聚类算法** | KMeans (scikit-learn) | 1.3.2 |
| **分类算法** | RandomForest (scikit-learn) | 1.3.2 |

### 3.2 核心字段说明

**users 表** - 系统用户
- `role`: 角色 (`admin` 管理员 / `analyst` 分析师 / `user` 普通用户)
- `password_hash`: bcrypt 加密密码
- `is_active`: 账号启用状态

**mental_health_data 表** - 心理健康调查数据 (30+ 字段)
- 基本信息: `age`, `gender`, `country`, `state`
- 工作情况: `self_employed`, `work_interfere`, `no_employees`, `remote_work`, `tech_company`
- 公司福利: `benefits`, `care_options`, `wellness_program`, `seek_help`, `anonymity`, `leave`
- 心理态度: `mental_health_consequence`, `coworkers`, `supervisor`, `mental_health_interview`
- 分析结果: `risk_level` (Low/Medium/High Risk), `cluster_id` (聚类标签)

**analysis_results 表** - ML 分析结果
- `analysis_type`: 分析类型 (`clustering` / `classification`)
- JSON 字段: `feature_importance`, `confusion_matrix`, `cluster_centers`, `hyperparameters`
- 性能指标: `accuracy`, `precision`, `recall`, `f1_score`, `silhouette_score`

**user_profiles 表** - 用户画像
- `risk_score`: 0-100 风险评分
- `tags`: JSON 标签数组 (如 `["青年员工", "科技公司", "远程工作"]`)
- `key_features`: JSON 关键特征
- `recommendations`: JSON 建议列表

## 四、核心功能实现

### 4.1 用户认证模块

**实现文件**: `app/api/auth.py` + `app/models/user.py`

**认证流程**:
```
注册 → 验证邮箱/密码 → bcrypt加密 → 存入users表

登录 → 查找用户(用户名或邮箱) → bcrypt验证密码
     → 生成 access_token (24h) + refresh_token (30d)
     → 返回 JWT Token + 用户信息

前端 → 存Token到Cookie("Admin-Token")
     → Axios拦截器自动附加 Bearer Token

后续请求 → @jwt_required() 装饰器验证 Token
        → get_jwt_identity() 获取用户ID
```

**API 接口**:
| 方法 | 路径 | 功能 | 认证 |
|------|------|------|------|
| POST | /api/auth/register | 注册 | 无 |
| POST | /api/auth/login | 登录 | 无 |
| POST | /api/auth/refresh | 刷新Token | refresh_token |
| POST | /api/auth/logout | 登出 | JWT |
| GET  | /api/auth/info | 获取用户信息 | JWT |
| PUT  | /api/auth/password | 修改密码 | JWT |

**密码加密实现** (`user.py`):
```python
def set_password(self, password):
    salt = bcrypt.gensalt()
    self.password_hash = bcrypt.hashpw(password.encode('utf-8'), salt).decode('utf-8')

def check_password(self, password):
    return bcrypt.checkpw(password.encode('utf-8'), self.password_hash.encode('utf-8'))
```


**数据清洗策略** (`DataService.clean_data`):

3. **类别型缺失值**: 众数填充 (如 Gender, Country)
4. **异常值处理**: 3σ原则裁剪 (age 超出均值±3σ的记录过滤)
5. **文本标准化**: `str.strip()` 去除首尾空白

#### 4.3.2 特征工程 (`feature_engineering.py`)

从原始数据中衍生出 **8 个核心特征**:

| 衍生特征 | 计算方式 | 用途 |
|---------|---------|------|
| `age_group_encoded` | pd.cut 年龄分5组(0-4) | 年龄离散化 |
| `support_score` | 5项福利指标(benefits/care_options/wellness_program/seek_help/anonymity)加权平均 | 公司支持度(0-1) |
| `stress_index` | work_interfere(0-3) + mental_health_consequence(0-2) + leave(0-3) 归一化 | 压力指数(0-1) |
| `company_size_encoded` | 6档公司规模映射(0-5) | 公司规模数值化 |
| `attitude_score` | coworkers + supervisor + interview + mental_vs_physical 归一化 | 心理态度评分(0-1) |
| `family_treatment_interaction` | family_history × treatment | 家族史×治疗交互 |
| `remote_tech_interaction` | remote_work × tech_company | 远程×科技交互 |
| `has_observed_consequence` | obs_consequence == 'Yes' | 是否观察到后果 |

#### 4.3.3 聚类分析 (`clustering.py`)

**算法**: KMeans++ (K-Means 改进初始化)

**核心参数**:
- `init='k-means++'`: 优化初始中心点选择
- `n_init=3`: 初始化次数
- `max_iter=50`: 最大迭代次数

**最优K值选择**: 轮廓系数法 (silhouette_score)，搜索范围 k=2~7

**输出**:
- 每条数据的 `cluster_id` 标签
- 聚类中心点坐标
- 轮廓系数 (评估聚类质量)
- 各群体规模和占比

**模型持久化**: `pickle` 序列化为 `.pkl` 文件

#### 4.3.4 分类分析 (`classification.py`)

**算法**: RandomForest (随机森林)

**训练流程**:
```
1. 目标变量编码: Low Risk=0, Medium Risk=1, High Risk=2
2. 数据分割: 70%训练 / 30%测试 (stratify分层抽样)
3. 标准化: StandardScaler
4. 网格搜索: GridSearchCV (5折交叉验证)
   - n_estimators: [50, 100, 200]
   - max_depth: [5, 10, 15, None]
   - min_samples_split: [2, 5, 10]
   - min_samples_leaf: [1, 2, 4]
5. 训练最优模型
6. 评估指标: accuracy, precision, recall, f1_score, 混淆矩阵
```

**输出**:
- 分类模型性能指标
- 特征重要性排序
- 混淆矩阵
- 模型文件 `classification_model.pkl`

### 4.4 数据预处理模块

**实现文件**: `app/ml/preprocessing.py`

**预处理流水线**:
```
原始数据
  │
  ├── 1. 缺失值处理
  │   ├── 数值型: SimpleImputer(strategy='mean')
  │   └── 类别型: 众数填充
  │
  ├── 2. 异常值处理
  │   └── 3σ原则: clip(mean±3*std)
  │
  ├── 3. 类别编码
  │   └── LabelEncoder: 类别→整数
  │
  ├── 4. 数值标准化
  │   └── StandardScaler: (x-mean)/std
  │
  └── 5. PCA 降维
      └── 保留85%方差的主成分
```

**预处理器支持 `save/load`**: pickle 序列化，便于推理时复用同一套预处理参数。

### 4.6 用户画像模块

**实现文件**: `app/services/profile_service.py` + `app/api/user.py`

#### 画像生成逻辑

**风险评分计算** (0-100):
```
基础分 = 50
+ stress_index > 0.5     → +15
+ family_history == Yes  → +10
+ treatment == Yes       → +10
+ work_interfere ∈ {Often, Sometimes} → +10
+ support_score < 0.3    → +10
──────────────────────────
上限100，下限0
```

**风险等级判定**:
- ≥70 → High Risk
- ≥40 → Medium Risk
- <40 → Low Risk

**标签生成规则**:
| 条件 | 标签 |
|------|------|
| age < 30 | 青年员工 |
| 30 ≤ age < 45 | 中年员工 |
| age ≥ 45 | 资深员工 |
| tech_company == Yes | 科技公司 |
| remote_work == Yes | 远程工作 |
| family_history == Yes | 家族病史 |
| self_employed == Yes | 自雇人士 |
| treatment == Yes | 正在治疗 |

**建议生成规则**:
- High Risk → "建议尽快寻求专业心理咨询" + "建议与上级沟通工作压力问题"
- Medium Risk → "建议关注心理健康状况" + "建议参加公司健康项目"
- Low Risk → "保持良好的工作生活平衡" + "定期进行心理健康自评"

#### 自评功能

用户填写问卷后，系统:
1. 构建单行 DataFrame → 特征工程
2. 尝试加载已训练的分类模型预测风险
3. 同时计算规则评分
4. 综合两者确定最终风险等级
5. 生成标签、关键特征、建议
6. 存入 `user_profiles` 表

## 五、前端实现

### 5.1 路由与权限

**路由配置** (`router/index.js`):

```
公共路由:
  /login          登录页
  /register       注册页

管理员/分析师路由 (roles: ['admin', 'analyst']):
  /dashboard      数据概览
  /analysis       特征分析
  /clustering     聚类分析
  /classification 分类预测
  /profiles       用户画像列表
  /profiles/:id   画像详情
  /data           数据管理
  /report         报告管理
  /assessment-records  自评记录
  /user-management     用户管理

普通用户路由 (roles: ['user']):
  /self-assessment  心理自评
  /my-report        我的报告
  /my-analysis      我的分析

公共:
  /settings       系统设置
```

**路由守卫逻辑**:
```
请求进入 → 检查Token
  ├── 无Token → 公开页面放行 / 否则跳转 /login
  └── 有Token → 获取用户信息 → 检查角色权限
        ├── 有权限 → 放行
        └── 无权限 → admin/analyst 跳转 /dashboard
                     user 跳转 /self-assessment
```

### 5.2 状态管理

**Pinia Store** (`store/modules/user.js`):
```
State:
  - token: JWT Token
  - userInfo: 用户信息对象

Getters:
  - isLoggedIn: 是否已登录
  - username: 用户名
  - userRole: 用户角色

Actions:
  - loginAction: 调用登录API → 存Token → 存userInfo
  - registerAction: 调用注册API
  - getUserInfoAction: 获取用户信息
  - logoutAction: 清除Token和userInfo
```

### 5.3 HTTP 请求封装

**Axios 实例** (`utils/request.js`):
```
基础配置:
  - baseURL: '/api'
  - timeout: 120000ms (120秒，适配分析计算)
  - Content-Type: application/json

请求拦截器:
  → 自动附加 Authorization: Bearer <token>

响应拦截器:
  → code !== 200/201 → ElMessage 错误提示
  → code === 401 → 跳转登录页
  → blob 类型直接返回 (文件下载)
```

### 5.4 Token 管理

**Cookie 存储** (`utils/auth.js`):
```
Key: 'Admin-Token'
过期: 7天
setToken(token) → Cookies.set('Admin-Token', token, {expires: 7})
getToken()      → Cookies.get('Admin-Token')
removeToken()   → Cookies.remove('Admin-Token')
```
